Sobre o projeto

O projeto investiga a evolução da taxa de desemprego e as diferenças entre regiões e estados. Também são analisadas renda média, vagas formais, inflação, setor predominante e nível de risco.

Nota: os dados utilizados são simulados e foram fornecidos para a atividade acadêmica. As conclusões não representam estatísticas oficiais.

Conclusão

A análise permite observar que o desemprego apresenta diferenças importantes entre regiões e UFs e que a dimensão temporal é essencial para compreender as oscilações da série. O dashboard reúne os resultados em uma interface interativa, permitindo explorar os dados de acordo com diferentes filtros.
